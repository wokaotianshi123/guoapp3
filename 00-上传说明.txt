七、功能说明（本批两大新特性）
    1. XBPQ 爬虫规则识别：自定义源录入时粘贴规则 JSON（wwgz 截取风格或
       gimyai p: 选择器风格均可），核心按「数组/标题/链接/图片/播放数组…」
       逐项截取，支持 || 备选、[包含:]/[替换:]、p: 选择器、GBK 转码、
       POST 搜索、@long-text 合并、尾逗号修复、$$$ 多线播放串。
       爬虫 jar（type=3 / spider）无法在 Go 核心执行，不渲染。
    2. 导入导出：桌面/移动 App 的自定义源页 + Web 版均可「导出 JSON」「导入文件」。
       导入兼容：自有导出格式 / 纯数组 / 「名称,网址」txt 清单 / TVBox 配置
       （sites/whitelist 数组、maccms api 地址收敛、ext 内嵌规则、jar 条目逐条跳过）。
       重复导入走更新而非报错；导出文件可直接喂回导入。
